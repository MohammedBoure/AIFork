# `src/components/ui/` Directory

This directory contains reusable presentation UI components for ThoughtGraph AI.

## Files
- `Navbar.tsx`: Top header navigation bar displaying graph statistics, active fork parent, sessions history trigger with session count badge, auto-layout triggers, templates, bilingual language toggle button (`AR` / `EN`), and API connection status.
- `CodeBlock.tsx`: Syntax-highlighted code rendering block with one-click clipboard copying.
- `Badge.tsx`: Versatile pill badges for roles, active models, merge synthesis status, and execution states.
- `Toast.tsx`: Lightweight notification toast overlay for user feedback.
