# `src/components/` Directory

This directory contains all UI components for ThoughtGraph AI organized by domain.

## Subdirectories
- `canvas/`: React Flow DAG visualizer, custom thought nodes, custom animated edges, and canvas controls.
- `prompt/`: Fork prompt bar with per-branch model selector and multi-branch synthesis merge modal.
- `settings/`: Settings drawer with API key management, connection testing, dynamic model discovery, and reusable model selectors.
- `modals/`: Export/Import modal, starter templates modal, and node inspection modal.
- `ui/`: Common presentation elements including navigation bar, code block syntax highlighter, badges, and toasts.
