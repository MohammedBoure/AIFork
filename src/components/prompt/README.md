# `src/components/prompt/` Directory

This directory contains prompt submission interfaces, branch context banners, per-branch model dropdowns, and synthesis modals.

## Files
- `ForkPromptBar.tsx`: Floating action bar at the canvas bottom displaying active parent node indicator, granular per-fork model selection dropdown, keyboard shortcut submission, and starter prompts.
- `MergeModal.tsx`: Synthesis dialogue presenting the selected branches, dedicated high-reasoning model picker, customized synthesis prompt presets, and multi-parent merge dispatch.
