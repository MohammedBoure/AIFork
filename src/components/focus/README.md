# `src/components/focus/` Directory

This directory contains distraction-free linear conversation reading and reply interfaces for exploring individual DAG branches.

## Files
- `FocusFlowModal.tsx`: Fullscreen conversation flow view displaying the strict chronological dialogue of a selected thought path as a natural chat interface. Features per-message copy buttons, inline prompt editing with response re-generation, fluid Arabic RTL/bilingual typography, native cursor text selection, and direct reply input with seamless DAG state synchronization.
